# Getting Started with ToDoInTime

Welcome! Follow the instructions below to install and start using **ToDoInTime** on your device.

---
- ## Download
  
  Download the latest version of the app from our GitHub repository:  
  https://github.com
  
  ---
- ## Installation Guide
- ### 🪟 Windows
- Installing on Windows is super easy:
	- 1. Download the setup file from GitHub Release
	- 2. Double-click the installer
	- 3. Follow the on-screen instruction
- That’s it — everything is handled automatically!
  ---
- ### 🐧 Linux
  
  You have two installation options:
- #### 🔹 Option 1: Flatpak (recommended)
	- 1. Download the `.flatpak` file from GitHub Release
	- 2. Make sure Flatpak is installed in your distro.
	  For example in Ubuntu/Debian:
	  
	  ```bash
	  sudo apt install flatpak
	  ```
	- 3. Install the app:
	  ```bash
	  flatpak install --user ToDoInTime.flatpak
	  ```
- #### 🔹 Option 2: Flathub-style install
	- Simply double-click the `.flatpak` file and follow your system prompts
- ---
- ### 📱 Android
	- 1. Download the `.apk` file from GitHub Release
	- 2. Open the file on your device
	- 3. Follow the installation instructions
- You may need to enable installation from unknown sources in your settings.
  ---
- ## Launch the App
  
  Once installed:
  * Open your applications menu
  * Search for **ToDoInTime**
  * Click the icon to start
