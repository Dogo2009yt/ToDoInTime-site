# Getting Started
- Download our app from [github](github.com) for you OS!
- ## On Windows
	- Download and execute the setup from github, it does all of the work for you!

- ## On Linux
	- Download the flatpak package from github
	- Install flatpak
	- Open the terminal and execute
	- ```bash
	  flatpak install --user ToDoInTime.flatpak
	  ```
	- **OR** You can install with Flathub by double clicking the *.flatpak* file

- ## On Android
	- Download the *.apk* file from github
	- Install following the instructions!
---
- After install you can search ToDoInTime icon in your desktop and execute it
